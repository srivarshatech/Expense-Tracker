# 💰 Expense Tracker Python

A command-line Expense Tracker built with Python that helps users manage daily expenses efficiently. The application supports adding, viewing, updating, deleting, and searching expenses, along with category-wise and monthly summaries. Users can also export their expense data to CSV and JSON formats.

---

## ✨ Features

- Add new expenses
- View all recorded expenses
- Update existing expenses
- Delete expenses
- Search expenses by category or description
- Category-wise expense summary
- Monthly expense summary
- Calculate total expenses
- Export data to CSV
- Export data to JSON
- User-friendly command-line interface

---

## 🛠️ Technologies Used

- Python 3
- CSV (Python Standard Library)
- JSON (Python Standard Library)

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/srivarshatech/Expense-Tracker-Python.git
```

### Navigate to the project

```bash
cd Expense-Tracker-Python
```

### Run the application

```bash
python expense_tracker.py
```
